# 许可证与商业使用

## 开源与商业许可

`@nucleusx/core` 并非免费商业软件，采用商业授权模式。

### 许可范围

- ✅ **允许使用**：
  - 技术评估
  - 内部验证
  - 非商业试用
  - 学习研究

- ❌ **禁止使用**：
  - 未授权的商业项目
  - 生产环境使用（未经许可）
  - 二次分发

- 🔒 **商业使用**：
