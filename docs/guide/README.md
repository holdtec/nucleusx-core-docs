# 指南

欢迎使用 NucleusX-Core 指南。本指南将帮助您快速了解和使用 NucleusX 运行时核心库。

## 什么是 NucleusX-Core？

`@nucleusx/core` 是一套面向 **中大型、多端、长生命周期应用** 的运行时核心库，用于 **统一管理业务逻辑的运行、状态与跨端行为**，降低平台差异对业务演进的影响。

本库以 **"业务逻辑长期稳定"** 为设计目标，适用于需要持续演进、多人协作、跨端运行的企业级项目。

## 核心能力

NucleusX Core 提供了一套统一的运行时治理能力，用于承载和保护业务逻辑资产：

- **业务逻辑去平台化** - 业务代码不直接依赖小程序/H5/UI框架API
- **统一运行时上下文** - 请求、状态、日志等能力通过统一入口访问
- **可配置式集成** - 根据运行环境注入不同实现，无需修改业务代码
- **适合复杂业务流程** - 支持多页面、多步骤、跨端一致的业务流程管理

## 适合的场景

- 企业级核心业务系统
- 多端（小程序/H5/App）统一业务逻辑
- 5人以上团队协作开发
- 需要长期维护、持续迭代的产品
- 对业务稳定性、可控性要求较高的系统

## 不适合的场景

- 一次性活动页/营销页
- 极简工具类项目
- 生命周期<3个月的实验性项目
- 仅单端、无长期维护计划的应用

> **重要提示**：NucleusX 并非"开发提速工具"，而是"长期治理工具"。
